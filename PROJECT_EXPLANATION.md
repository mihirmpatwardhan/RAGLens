# RAGLense Project Explanation

This repo now focuses on the product-ready core:

- Clerk authentication with verified user sessions
- Knowledge-base scoped uploads
- Backend-backed ingestion and recent pipeline runs
- Grounded chat with retrieval traces
- Live analytics from persisted workspace data

Older demo-only dashboards have been replaced with honest placeholders so the UI no longer claims features that are not persisted or wired to the backend yet.

See `ARCHITECTURE.md` for the current frontend/backend structure and request flow.
